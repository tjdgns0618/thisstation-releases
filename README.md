# 이번정류장 Android 배포

[최신 APK 다운로드](../../releases/latest/download/thisstation.apk)

버스 탑승 중 현재 정류장과 하차 시점을 안내하는 Android 앱입니다. 서울·광주 및 TAGO에서 제공한 138개 지역의 수집 데이터를 포함합니다. 모든 지역의 모든 노선을 보장하지는 않습니다.

이 저장소는 APK 배포와 변경 내역만 제공합니다. 앱 소스와 환경 설정은 포함하지 않습니다.

최초 설치는 최신 Release의 `thisstation.apk`를 사용하세요. 업데이트 기능이 포함된 버전부터는 앱 실행 시 새 Release가 있는지 확인하고, 동의하면 APK를 다운로드해 Android 설치 화면을 엽니다. 마지막 설치 확인은 사용자가 직접 누릅니다.

직접 APK로 배포하는 개발·테스트 버전이며 Google Play에서 배포하는 버전은 아닙니다.
